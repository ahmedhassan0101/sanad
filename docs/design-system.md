# سند — الهوية البصرية ونظام التصميم

## الفكرة

«ورقة وحبر هادئ»: مركز التحفيظ مكان طمأنينة وانضباط يومي، لا تطبيق ترفيهي. الهوية محايدة دافئة (رمادي مزرقّ كورق المصحف) مع لون علامة واحد عميق (تركواز مزرقّ بلون الحبر)، وتباين عالٍ يقرأه كبار السن تحت إضاءة المسجد، وزخرفة صفرية — كل عنصر له وظيفة. تُغيَّر الهوية كلها من `src/app/globals.css` فقط.

## الألوان

| الدور | فاتح | داكن |
|---|---|---|
| محايد bg/fg | `#F5F7F7` / `#14222A` | `#0A1519` / `#EDF3F4` |
| العلامة primary (تركواز حبري) | `#0A6C7E` | `#4FB3C4` |
| ثانوي (رمادي مزرقّ) | `#3D5A73` | `#8FB0CC` |
| لمسة تمييز (كهرماني، للشارات فقط) | `#C28235` | `#E0A04A` |
| نجاح | `#1B7A4E` | `#4CC38A` |
| تحذير | `#9A5B00` | `#E6AE4C` |
| خطر | `#B83245` | `#F0717F` |
| معلومة | `#2565A8` | `#6AB0E8` |
| حضور: حاضر/غائب/متأخر/بعذر | نجاح/خطر/تحذير/معلومة (نفس القيم) | نفس القيم الداكنة |

كل لون دلالي له ثلاثي (`color`, `muted`, `muted-foreground`) — النص على `muted` يحقق 4.5:1، والعناصر 3:1، في الوضعين. الداكن مصمم يدويًا (أسطح مزرقّة داكنة) وليس عكسًا آليًا.

## الأسطح والظلال

أربع طبقات: `canvas` (الخلفية) ← `surface` (البطاقات) ← `raised` (منبثقات/قوائم) ← `overlay` (حوارات/تنبيهات)، تقابلها توكنز `background`/`surface-1`/`surface-elevated`/`surface-overlay`. خمسة ظلال `elevation-0..4` (خفيفة نهارًا، أعمق ليلًا). نصف القطر: 6/8/12/16 للعناصر الصغيرة→البطاقات، وكامل للشارات.

## النصوص والمسافات والحركة والأيقونات

Tajawal للعربي وInter للاتيني/الأرقام (أرقام tabular في البيانات عبر `font-data`)؛ سلّم `display-lg..caption` في التوكنز. حاوية الصفحة `page-container` (16/24/32). الحركة: 120/200/300ms بتوقيت ناعم، وتُحترم `prefers-reduced-motion` (إلغاء شبه كامل). الأيقونات lucide بسماكة واحدة (`size-4` داخل العناصر) وأهداف لمس ≥ 40px.

## الجداول والمكونات

كثافتان: `comfortable` (صف ~52px افتراضي) و`compact` (~40px للقوائم الطويلة). المكونات الأساسية: زر primary واحد بارز في كل شاشة، badge مطفي (muted) للحالات، بطاقة إحصاء برقم واحد كبير، جدول به header هادئ وعمود إجراءات، `ConfirmDialog` للإتلافيات، و`EmptyState` (أيقونة+جملة+إجراء) بدل الفراغ الميت.
