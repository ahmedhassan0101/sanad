# الشاشات والصفحات

## كيف تقرأ هذا الملف
- صفحة لكل مسار موجود فعلًا في `src/app/`.
- لكل صفحة: ماذا ترى، وماذا تفعل، وبياناتها من أين، وأين تذهب بعد كل إجراء.
- آخر قسم للنوافص.

## `/` — البداية (`app/page.tsx`)
- ترى: كارت «سَنَد» + زري الدخول والحساب.
- البيانات: الجلسة فقط. المسجل يُحوَّل تلقائيًا إلى `/onboarding`.
- لا أفعال هنا.

## `/login` — الدخول (`app/login/*`)
- ترى: زر Google (مشروط بالمفاتيح) + حقلا الإيميل والباسورد (إظهار/إخفاء) + رابطا الحساب والنسيان.
- الفعل: دخول ← نجاح يحول إلى `/onboarding`، فشل يعرض رسالة حمراء + تنبيهًا.
- المكونات: `Card` و`LoginForm` (`FormInput` + `FormSubmitButton`).

## `/register` — حساب جديد (`app/register/*`)
- ترى: الاسم + الإيميل + الباسورد (مع تلميح 8 أحرف).
- الفعل: إنشاء ← إنشاء الحساب + دخول تلقائي ← `/onboarding`. الإيميل المكرر رسالته الخاصة.
- ملاحظة: رابط التفعيل يُطبع في الـ logs — افتح الـ terminal لتنسخه.

## `/forgot` و`/reset` — الاستعادة (`app/forgot/*`, `app/reset/*`)
- `/forgot`: إيميل واحد. الرد دائمًا «إن وُجد الحساب ستصلك رسالة» حتى لو لا حساب.
- `/reset`: يفتح فقط برابط صحيح (`email`+`token`). حفظ ناجح ← `/login`. رابط منتهي ← رسالة تطلب رابطًا جديدًا.

## `/verify` — التفعيل (`app/verify/page.tsx`)
- لا فورم فيها: النجاح يحوّل مباشرة إلى `/onboarding`، والفشل يعرض بطاقة بزر عودة.

## `/verify-pending` — انتظار التفعيل (`app/verify-pending/*`)
- ترى: «فعّل بريدك أولًا» + إيميلك + زر إعادة إرسال (حد 3/ساعة) + زر خروج. لا مخرج آخر.
- غير المفعّل فقط: العضو يُحوَّل إلى `/dashboard`، والمنصة إلى `/platform`، والموثق بلا مركز إلى `/onboarding`.

## `/onboarding` — البداية (`app/onboarding/*`)
- ترى: ترحيبًا بالاسم + أزرار «دخول» لكل عضوية فعالة (تثبت الكوكي عبر `setActiveOrg` ثم `/dashboard`) + 3 كروت.
- الكروت: إنشاء مركز (يعمل) / كود دعوة (يعمل) / متابعة طفلي (معطل).

## `/onboarding/create-center` — إنشاء مركز (`app/onboarding/create-center/*`)
- ترى: الاسم + التواصل + العنوان + برامج (checkboxes من الكتالوج) + مخصص + زر إنشاء.
- الفعل: نجاح ← `/dashboard` (الكوكي يُثبَّت تلقائيًا). فشل ← رسالة (منها: فعّل بريدك، الحد 3 مراكز).
- البيانات الخارجة: مركز + فرع رئيسي + عضوية مالك + برامج (transaction واحدة).

## `/onboarding/enter-code` — الكود (`app/onboarding/enter-code/*`)
- ترى: حقل كود واحد + زر انضمام.
- الفعل: كود صحيح ← عضوية بالدور المحدد في الدعوة ← `/dashboard`. كود خاطئ/منتهي/مستخدم ← رسالة. العضو الحالي ← «أنت عضو بالفعل».

## `/dashboard` — اللوحة (بهيكل: علوي + جانبي)
- الإطار (`layout.tsx`): شريط علوي (اسم المركز + مبدّل المركز إن تعددت + مبدّل الفرع إن تعددت + قائمة المستخدم: خروج/سمة) وشريط جانبي (240px، درج تحت xl): الرئيسية، الفريق (مشرفون فقط)، الطلاب/المجموعات/الحضور، الإعدادات (غير المعلم). العنصر النشط مميز.
- الصفحة الرئيسية: ترحيب + عدد الفروع (حسب الفرع المختار) + البرامج + زر إدارة الفريق للمشرفين.
- `team`: دعوة جديدة (الدور حسب دورك + الفرع مخفي لو واحد + المدة حتى 7) والكود يظهر مرة واحدة مع نسخ وواتساب + الدعوات الفعّالة بزر إلغاء + الأعضاء (تغيير دور/تعطيل بحماية المنشئ وآخر أدمن). المعلم لا يراها (تحويل سيرفر).
- `groups` و`attendance` و`settings`: «قريبًا» (الإعدادات ترفض المعلم).

## `/dashboard/students` — الطلاب (`app/dashboard/students/*`)
- ترى: 4 إحصائيات + فلاتر (بحث debounce، مستوى، نوع، حالة افتراضي نشط، بيانات ناقصة، ونشاط معطّل) + جدول (أفاتار/مستوى/نوع/عمر/هاتف ولي الأمر/أنشطة "—"/موضع الحفظ/شارة نقص/عرض/تعديل/أرشفة) + ترقيم + زر وحيد «إضافة طالب».
- `new`: فورم فارغ (الفرع يظهر لو تعددت الفروع). `[id]`: بطاقة (معلومات/أولياء بروابط tel ونسخ/حفظ بداية وحالي/كود ولي الأمر مع نسخ وتجديد/ملاحظات/أنشطة وتقارير placeholder) + تعديل/أرشفة/حذف نهائي بتأكيد الاسم (مؤرشف ومدراء فقط). `[id]/edit`: نفس الفورم (الحفظ: الموضع فقط).
- id خارج النطاق ← 404. متجاوبة للموبايل (جدول بتمرير أفقي).

## `/platform` — المنصة (`app/platform/page.tsx`)
- ترى: بطاقة لكل مركز (اسم/فروع/أعضاء/برامج/تواصل) — أرقام فقط.
- للأدمن العام فقط (يُزرع بالـ seed). غيره يُحوَّل إلى `/onboarding`.

## `/ui-demo` — المعرض (`app/ui-demo/*`)
- ترى: كل الأزرار والحالات وحقلي معطل/قراءة فقط وفورم تجريبي كامل (إنشاء وتعديل) وأزرار toast وهيكل تحميل ومبدل السمة.
- للتطوير فقط: في الإنتاج تُرجع 404. غير مرتبطة من أي صفحة.

## النواقص والـ placeholders
- زر «متابعة طفلي»: معطل، لا صفحة ولا منطق له (كود ولي الأمر جاهز للربط لاحقًا).
- صفحات المجموعات/الحضور/الإعدادات: «قريبًا» (الطلاب مبنية). لا ملف شخصي.
